# STL orientation optimization

An STL review tool with interactive 3D previews, geometry-based orientation search, and an experimental slicer-trained regression model. Based on https://first-print-right.onrender.com/, retrieved November 13, 2026. The actual publicly served HTML, CSS, and JavaScript are preserved under `original/`. `public/` is the runnable copy, with the same Three.js version served locally rather than from a CDN. The private server's source is not exposed by the website; `server.mjs` is a newly written replacement for its two API routes.

## Run

Install Node.js 22.9 or later, then open a terminal in this folder:

```sh
npm start
```

Open http://127.0.0.1:3000. No npm dependency installation is needed: the required Three.js 0.160.0 modules are included with their MIT license under `public/vendor/three/`. Google Fonts loads Inter and Archivo online, with system fonts as fallback.

## Machine learning

A local ridge regression model predicts **support material** and **print time** from geometry and orientation features. Its training labels are generated by **PrusaSlicer 2.9.7**, using 24 procedural parts in 8 orientations each. The dataset, fixed slicing profile, trainer, fitted model, and evaluation results are included; no API key is needed for ML.

In the review panel, choose **Use ML when validated** or **Geometry formulas**. The same estimator drives orientation ranking and displayed estimates. Each prediction target activates only after its held-out error beats both the original formulas and a mean baseline, and every compared pose is within its feature ranges. Otherwise the app explains why it uses formulas. Validation is split by part so orientations of one mesh never appear in both training and validation.

This is an experimental model trained on a small set of generated parts and one fixed PLA profile, not proof of accuracy on arbitrary real-world models. **Failure risk remains a heuristic, not an ML failure probability.** Physical print outcomes are needed to train that target. The shipped model enables **ML print time**; support and part plastic remain formula-based because support regression did not improve on the baseline. Electricity derives from the selected time estimate. Slicer suggestions in ML mode show the calibration profile.

```sh
npm run train:ml
npm test
```

Read [ML design and limitations](docs/ml.md), [data generation instructions](docs/data-collection.md), and the [model card](docs/model-card.md). The original public frontend remains unmodified under `original/` for comparison.

## Optional AI explanation

Copy `.env.example` to `.env`, set your own `OPENAI_API_KEY`, and restart. The key stays on the server. Without a key, mesh analysis, estimates, orientation comparison, and STL downloads still work; the explanation is generated locally. The replacement server sends numeric analysis, risk, fit, and rotation information to OpenAI, excluding the filename and STL mesh. Do not put credentials in `public/` or commit `.env`.

The original site's AI model, credentials, prompts, and private backend implementation cannot be recovered from its URL. The replacement defaults to `gpt-4.1-mini`; configure a model available to your account. Set `OPENAI_REASONING_EFFORT` only if your selected model supports it.

## Included behavior

- STL file selection and drag/drop, with the original 100 MB limit.
- Built-in stove knob sample.
- Client-side geometry analysis and orientation search.
- Interactive 3D viewer, camera presets, original/optimized comparison, and overhang highlighting.
- Before/after material, time, energy, risk, contact, and overhang estimates.
- Rotation approval, slicer suggestions, and binary STL export.

Estimates use either the original geometry formulas or a validated local ML model trained on slicer estimates; neither is a print guarantee. The sample is made from overlapping cylinder meshes, as on the original.

## Download behavior

Select **Confirm & download**, or **Download again** after approval. The output is `<filename>_optimized.stl`, typically saved to your browser's Downloads folder. The original site shows its success screen immediately after initiating the download; this does not prove the browser saved it. In Codex's browser, a download may save without displaying a prompt. Check Downloads or use a regular browser if its download settings block the save.

## Verify

```sh
npm test
```

Tests cover regression training, grouped validation, domain/profile fallback, scoring and displayed metric consistency, baseline geometry equivalence, G-code labels, static serving, and mocked optional AI requests. GitHub Actions runs the tests and checks reproducible model training. Live AI requires your own key and is not tested by default.
